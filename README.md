# Bookshelf Reader

A simple EPUB reader that runs in your browser.

- Drop `.epub` files in to add them to your library
- Six reading themes, adjustable text size, serif/sans fonts, single or two-page layout
- Select text while reading to save it as a quote (with an optional note)
- All quotes in one searchable tab, with a link back to the spot in the book
- Progress bar for each book; reopening a book resumes where you left off

Your books and quotes are stored only in the browser you use (IndexedDB). Nothing is uploaded.
